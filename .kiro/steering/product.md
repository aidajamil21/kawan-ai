# Product Overview

## Kawan AI - Malaysian AI Buddy Mobile App

Kawan AI is a hyperlocal AI buddy mobile app prototype designed specifically for life in Malaysia. The app features a cute animated mascot character that provides personalized recommendations for food, activities, and places to visit based on Malaysian culture, local context, location, mood, time, and budget.

### Target Users
- **University Students**: Budget-conscious users seeking affordable local experiences
- **Newcomers to Malaysia**: Tourists and expats learning Malaysian culture and language  
- **Local Malaysians**: Users seeking authentic local recommendations and hidden gems

### Core Value Proposition
- **Cultural Authenticity**: Deep integration of Malaysian culture, language patterns, and local context
- **Mascot-First Experience**: Animated character interface that embodies Malaysian friendliness
- **Adaptive Communication**: Progressive slang learning system with cultural education
- **Hyperlocal Intelligence**: Knowledge of Malaysian neighborhoods, food culture, and social customs
- **Smart Journey Planning**: Intelligent route optimization with cultural timing considerations for multi-destination trips

### Key Features
- Four specialized AI agent modes (Jom Lepak Lu, Tempat Healing, Makan Boss, Jalan-Jalan Cari Makan)
- Adaptive language slider from Full English to Full Malaysian Slang
- Dietary category system respecting Malaysian religious and cultural diversity
- Smart journey planner for multi-destination trips with cultural timing optimization
- Voice interaction with Malaysian accent
- Map integration with Waze and Google Maps navigation
- Malaysian flag-inspired visual design (red, blue, white, yellow)

### Project Context
This is a **hackathon prototype** designed for rapid development and impressive demonstration within a 4-hour timeframe. The focus is on cultural authenticity, visual impact, and core functionality demonstration rather than production-ready scalability.
